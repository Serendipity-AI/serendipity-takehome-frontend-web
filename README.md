# Serendipity AI - Web Frontend Takehome

## Get started

1. Install dependencies

   ```bash
   yarn install
   ```

2. Start the app

   ```bash
   yarn dev
   ```

## Structure of the project

This project has the following high level structure:
- `/src/app` - next router file based routes
- `/src/api` - api related functions
- `/src/features` - app pages
- `/src/components` - ui components
- `/src/hooks` - some hooks used in the project (currently tanstack query related logic)
- `/src/types` - types used in the project
